# Prototype PR skeleton

This folder demonstrates the expected structure for small, reviewable PRs.

Contents:
- `test_stub.py` — trivial passing test to verify CI plumbing.

Checklist for a new PR:
- Include a short problem statement and approach.
- Add tests (happy path + 1 edge case).
- Update docs if behavior changes.
- Provide a rollback plan (feature flag or revertable commit).
